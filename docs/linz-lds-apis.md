# LINZ LDS APIs (quick reference)

Official documentation and portals live on [LINZ Data Service](https://data.linz.govt.nz/) (API keys, dataset pages, and WFS endpoints).

For this repository, the NZ Addresses WFS ingest is documented in [`pipelines/linz_nz_addresses/README.md`](../pipelines/linz_nz_addresses/README.md). Local CLI defaults use [`pipelines/linz_nz_addresses/linz_nz_addresses.yml`](../pipelines/linz_nz_addresses/linz_nz_addresses.yml).
